## কী কী আছে
- 🗺️ বড় 3D ওপেন ওয়ার্ল্ড শহর — ধানমন্ডি, গুলশান, মিরপুরসহ এলাকার নাম, বিল্ডিং, পাম গাছ, বিচ
- 🚗 গাড়ি চালানো, ট্রাফিক, গাড়ি ছিনতাই
- 👮 পুলিশ সিস্টেম — অপরাধ করলে ⭐ ওয়ান্টেড বাড়ে, পুলিশ তাড়া করে
- 🎯 বাংলা মিশন — গোলাপি আলোর স্তম্ভে পৌঁছাও, টাকা কামাও
- 🔧 গ্যারেজ — ৳৫০০ দিয়ে ওয়ান্টেড মোছা + স্বাস্থ্য ফেরত
- 🎚️ গ্রাফিক্স হাই/লো, ⏸ পজ, ফুলস্ক্রিন, সাউন্ড টগল
- 📱 ফোনে টাচ কন্ট্রোল, কম্পিউটারে WASD
