## কী কী আছে
- 🗺️ বড় ওপেন ওয়ার্ল্ড শহর — মতিঝিল, ধানমন্ডি, গুলশানসহ এলাকার নাম, বিচ ও সমুদ্র
- 🚗 ৩০+ গাড়ি — যেকোনো গাড়িতে উঠে চালানো যায়, ট্রাফিক AI গাড়ি চলাচল করে
- 👮 পুলিশ সিস্টেম — অপরাধ করলে ⭐ ওয়ান্টেড বাড়ে, পুলিশ তাড়া করে, ধরা পড়লে জরিমানা
- 🎯 বাংলা মিশন — ডেলিভারি, ট্যাক্সি যাত্রী পৌঁছে দেওয়া, গন্তব্যে পৌঁছানো; টাকা কামাই
- 🔧 গ্যারেজ — টাকা দিয়ে গাড়ির রং বদলে ওয়ান্টেড মোছা যায়
- 📱 ফোনে টাচ কন্ট্রোল (D-pad + বোতাম), কম্পিউটারে WASD/তীর চিহ্ন
- 🗺️ লাইভ মিনিম্যাপ, মিশন তীর-নির্দেশক
